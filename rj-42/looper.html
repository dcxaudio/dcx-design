Floppy (Song In): solta a música inteira aqui (WAV, MP3...). O LCD mostra a forma de onda dela.
Source BPM: o tempo original da música, achado sozinho ou pelo Tap Tempo. Target BPM: o tempo que você quer, no knob Target Tempo.
Vari-Speed / Stretch / Off: como chegar no tempo alvo. Vari-speed muda o tom junto (como o 45 RPM); Stretch mantém o tom.
Search + Set In: o jog percorre a música; Set In marca o tempo forte onde o loop começa. Nudge anda o início um tempo para cada lado.
Loop Length 1/2/4/8: quantos compassos o loop tem. O fim é calculado pelo BPM, então o loop fecha certinho.
Store + Loop Memory: Store guarda o loop marcado num dos 8 espaços. Dá para tirar vários loops da mesma música.
Send Loop: manda o loop escolhido para um pad do RJ-2000, para o RJ-950 ou salva em arquivo (WAV ou MP3).
Fade: um fade curto nas pontas do loop, para não estalar quando ele repete.
