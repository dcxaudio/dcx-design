# DCX Design

Mockups e rascunhos visuais dos aparelhos da DCX Audio, antes de eles virarem código.

Cada aparelho tem uma pasta. Os arquivos são HTML puro: basta abrir no navegador.

| Pasta | Aparelho | Arquivos |
|---|---|---|
| `rj-42/` | RJ-42 Looper | `looper.html` |

Os instrumentos ficam em repositórios próprios ([rj-2000](https://github.com/dcxaudio/rj-2000), rj-950, rj-42), e o rack que junta todos fica no [dcx-studio](https://github.com/dcxaudio/dcx-studio).
